## foldable

Плагин для Chrome и Firefox, позволяющий управлять Swagger UI табами.
Он добавляет на страницу Swagger UI оверлей с кнопками для свертывания и развертывания табов. Это полезно при большом
количестве эндпоинтов, среди которых нужно найти нужный.

Для использования в своем браузере необходимо сбилдить нужную версию и установить ее в браузер.
Перед билдлом убедитесь, что имеете нужную версию Bun на своем компьютере.
Запустите команду 
```cmd
bun run build.ts chrome
```
или
```cmd
bun run build.ts firefox
``` 
в папке с файлами репозитория, после чего все содержимое плагина окажется в папке `output`.
